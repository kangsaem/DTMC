# DTMC — Desktop Music Composer

원곡을 넣으면 분위기가 비슷한 새 곡을 피아노·스트링 등 연주로, 원하는 길이(10초~10분)만큼 만들어 주는 윈도우용 프로그램입니다.

- 모든 처리는 사용자 컴퓨터 안에서 이뤄집니다(생성 엔진: ACE-Step 1.5).
- NVIDIA GPU가 있으면 고품질 모드, 없으면 CPU 경량 모드로 자동 실행됩니다.
- 압축을 풀어 바로 쓰는 포터블 프로그램입니다. 생성 엔진은 첫 실행 때 한 번 내려받습니다.

## 사용법
1. 압축을 풀고 `DTMC.exe` 실행 → [AUTO]
2. 원곡(MP3 · WAV · FLAC · M4A 등)을 끌어다 놓기(우클릭 = 파일·폴더 추가)
3. 오른쪽 단계 줄에서 설정
   - **분석**: 템포·조성·분위기 자동(직접 고를 수도 있음)
   - **생성**: 악기(최대 3개) · 길이(원곡 길이/직접) · 원곡 반영 정도(기본 낮음) · 후보 수 · [악기 시험]
   - **출력**: 형식(MP3 · FLAC · M4A · OGG · WAV) · 저장 폴더
4. [AUTO] — 처음에는 생성 엔진 설치 창이 먼저 뜹니다(수십 분 이상, 한 번만)
5. 끝나면 결과 줄에서 ▶ 미리듣기 · [폴더]

- 설정·로그·작업 기록: `내 문서\DTMC` (오류가 나면 `logs` 폴더의 `dtmc.log`, `engine.log`를 보내 주세요)
- 엔진 설치 위치: 프로그램 폴더의 `engine`(경로에 한글·띄어쓰기가 있으면 `드라이브:\DTMC_engine`)

## 원곡 반영 정도
- **낮음(기본)**: 원곡 소리는 엔진에 보내지 않고 분석한 템포·조성·분위기만 씁니다(저작권 안전).
- **중간·높음**: 원곡을 참고 음원으로 보내 흐름을 따라갑니다. 판매·공개용이면 원곡과 너무 닮지 않았는지 꼭 확인하세요.

권리가 있는 음원만 넣어 주세요. 개발 진행 상황은 [HANDOFF.md](HANDOFF.md)를 보세요.

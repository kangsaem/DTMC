# DTMC — Desktop Music Composer

원곡을 넣으면 분위기가 비슷한 새 곡을 피아노 또는 스트링 연주로, 원하는 길이만큼 만들어 주는 윈도우용 프로그램입니다.

- 모든 처리는 사용자 컴퓨터 안에서 이뤄집니다.
- NVIDIA GPU가 있으면 고품질 모드, 없으면 CPU 경량 모드로 자동 실행됩니다.
- 압축을 풀어 바로 쓰는 포터블 프로그램입니다. 생성 엔진은 첫 실행 때 한 번 내려받습니다.
- 결과는 MP3, FLAC, M4A, OGG, WAV로 내려받을 수 있습니다.
